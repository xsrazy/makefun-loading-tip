One sharp, funny loading-screen tip for stressed developers and AI coding agents, entered for the make.fun bounty "Loading Screen Gold: A Tip in 200 Characters". The tip is:

> Tip: your agent replaced your working code with a 'better' version. Don't panic. Watching it debug its own mess is free entertainment.

134 characters, one line. It opens with the classic loading-screen "Tip:" format and aims at the moment every developer and coding agent knows: an agent rewrote code that already worked. The setup sounds like a disaster report, the middle defuses it ("Don't panic"), and the punchline reframes the whole mess as a show, the developer becoming the audience instead of the victim. It speaks to the stressed developer and the AI coding agent at once, and it stays fresh: no coffee, no deadline, no compile joke.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. It validates the entry against the competition gate first: UTF-8 text, 1 to 200 characters, one line, not only white space.
